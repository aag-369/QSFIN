THE GAP

India's forensic infrastructure is overwhelmed

These are documented, current figures — not hypothetical stakes. QSFIN exists because this combination of problems has no existing Indian system addressing it end to end.

The BNSS (2024) now legally mandates forensic investigation for serious offences — states have until roughly 2029 to comply, because the infrastructure doesn't yet exist. Forensic evidence is routinely rejected or weakened in Indian courts specifically because chain-of-custody and methodology can't be adequately demonstrated — the exact gap QSFIN's explainability layer targets. No existing Indian system combines scene reconstruction, multi-agency intelligence, and court-ready explainable reasoning.

HOW IT WORKS

Five stages, one case, one live backend

Click any stage to expand it. Numbers marked LIVE are fetched from the running QSFIN backend, not hardcoded.

Rooms, evidence markers, ballistic trajectories, and chain-of-custody records are modeled as a queryable digital twin built from structured scan data — replacing static photographs with an explorable, permanent virtual scene that never degrades once the physical scene is released.

LIVE – evidence markers · – rooms in the current case twin

Ballistics & Trace Evidence, Digital Forensics, Network Analysis, and Timeline Reconstruction agents each independently analyze one slice of the case and post structured, confidence-scored findings to a shared blackboard — mirroring how a real investigative team is organized, and keeping every sub-conclusion auditable in isolation.

LIVE – findings posted by – agents on the current case

A statistical aggregation of every agent finding ("the neural part") is adjusted by a small set of explicit, named, human-readable rules ("the symbolic part") — such as discounting evidence with a broken chain of custody. Every ranking ships with a full plain-language explanation chain, because a black-box confidence score is not admissible or persuasive in a courtroom — a traceable reasoning chain is.

LIVE top-ranked scenario for the current case: –

Competing scenarios and contested evidence are jointly formulated as a QUBO (Quadratic Unconstrained Binary Optimization) — the same mathematical form used by real quantum annealers and QAOA circuits — and solved via simulated annealing, verified against an exact brute-force optimum. This runs on classical hardware today, using quantum-inspired mathematics — it is built to be quantum-ready as real quantum hardware matures, and makes no claim of running on one now.

LIVE – — try it yourself in the Live Demo section below.

Multiple simulated police/forensic agencies each train a local model on their own case data; only model parameters — never raw case records — are combined via FedAvg (federated averaging) into a shared triage model. Demonstrated result: federated accuracy lands close to a fully-centralized-data ceiling, both above local-only performance, without any agency's raw data ever leaving that agency.

ROADMAP

From prototype to something a real agency could pilot

  1. 1

    Real case data

    Swap the synthetic case file for a real or ethics-cleared dataset — every module already reads a fixed schema, so nothing downstream needs to change.

  2. 2

    Real 3D capture pipeline

    Replace hand-authored scene coordinates with photogrammetry/LiDAR output feeding the same digital-twin interface.

  3. 3

    Trained-model agents

    Add CV models for trajectory/blood-spatter analysis and NLP for witness statements, behind the same finding/confidence/reasoning contract.

  4. 4

    Legal validation of explanations

    Work with Indian evidence-law expertise to check the rule-firing explanations against real BNSS / Sakshya Adhiniyam admissibility requirements.

  5. 5

    Real quantum-hardware benchmarking

    Benchmark the QUBO on a real annealer or QAOA circuit against the classical baseline already in this repo, at growing case-graph scale.

  6. 6

    Real multi-agency federated deployment

    Move from simulation to a real cross-agency protocol with secure aggregation, under actual institutional agreements.
